# 把你的私有视频放在这里

把 `.mp4` / `.webm` 文件放进这个文件夹，例如：

    relay/videos/1.mp4
    relay/videos/2.mp4

部署到 Railway（或其它托管）后，用以下地址填到小程序里
（🔑 → 设置视频列表，每行一个）：

    https://你的域名/v/1.mp4
    https://你的域名/v/2.mp4

这样视频走你自己的服务器，不经过任何第三方 —— 和聊天一样私有。

> 不填也行：默认会尝试播放几个公开测试视频。
> 注意：公开测试视频在某些地区（如中国大陆）可能加载慢或被墙，
> 自托管是最稳、最隐私的方案。
